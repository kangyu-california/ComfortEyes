ComfortEyes is a lightweight Windows screen overlay application designed to reduce eye strain during extended computer uses. It works by applying two customizable image filters (one for each eye) over the entire desktop, making fonts crisp and easier to read at a glance, giving your display the calm, paper-like quality of an e-ink screen. The result is a more comfortable viewing experience that reduces glare and eye fatigue.

Image Filter Settings:

* X Shift / Y Shift (in pixels)
These slide the filter layer slightly to the left/right (X) or up/down (Y). Nudging the layer off-center creates a subtle outline effect around text and edges, making them appear sharper and more emphasized. Large absolute shift value creates 3D effect for text.

* Blend ratio (%)
This controls how strongly the filter layer is mixed over your screen. A lower value gives a lighter, more transparent effect, while a higher value makes the text edge more pronounced but the screen will be dimmer.
